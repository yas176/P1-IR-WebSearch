# P1-IR-WebSearch   
A Python information-retrieval project that builds and queries an inverted index using the Reuters corpus.

# Features
- Parses Reuters .sgm documents.  
- Builds indexes using naive indexing and the SPIMI algorithm.  
- Supports single-term and Boolean AND queries.  
- Compares index correctness and performance.    

# Requirements
- Python 3  
- NLTK  
- Reuters corpus files in a root-level data/ directory
  
# Install the dependency:
pip install nltk 

# To run the project 
python src/challenge.py
